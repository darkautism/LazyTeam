Worker-local runtime knobs

These are read by each worker process, so different machines may intentionally use different values. They are not secrets and are not stored in Host SQLite.
  • LAZYTEAM_HARNESS_PROBE_INTERVAL_SECS — watchdog probe interval, default 120s
  • LAZYTEAM_HARNESS_PROBE_GRACE_SECS — probe response grace, default 30s
  • LAZYTEAM_HARNESS_MAX_MISSED_PROBES — missed probes before abort, default 3
  • LAZYTEAM_HARNESS_MAX_INACTIVE_PROBES — inactive probes before abort, default 3
  • LAZYTEAM_HARNESS_TOOL_STALL_SECS — one tool with no progress, default 1800s
  • LAZYTEAM_REVIEW_SOFT_TOOL_BUDGET — reviewer soft tool-call budget, default 12
  • LAZYTEAM_REVIEW_HARD_TOOL_BUDGET — reviewer hard tool-call budget, default 20
Deployment/security values such as database path, public URL, OAuth/admin/worker secrets, Git credential key, allowed OAuth/redirect hosts, sandbox spec and daemon user-namespace IDs remain environment-only and are deliberately not editable here.
